feat(RichTextEditor): the toolbar uses plain Fondue components. Toggles show Fondue `Button`'s pressed state, toolbar controls use the regular `Button` size, the text style picker is the regular `Select`, and a vertical `Divider` parts the groups. The editor no longer restyles any Fondue component, so the toolbar is taller and touch screens no longer get 44px targets.
