feat(RichTextEditor): the toolbar uses plain Fondue components. Toolbar controls use the regular `Button` size, a toggle that is on switches from the weak to the default emphasis, the text style picker is the regular `Select`, and a vertical `Divider` parts the groups. The editor no longer restyles any Fondue component, so the toolbar is taller and touch screens no longer get 44px targets.
