feat(RichTextEditor): set the gap between a list marker and its item text with `gap` in a bullet or numbered list level's look. A string marker such as `'•'` gets no room of its own, so set `gap` to keep it off the text. With `gap` set, leave the trailing space out of the string: both apply, so the room doubles. Left out, the look does not change.
