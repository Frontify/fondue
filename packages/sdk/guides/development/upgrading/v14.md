# Upgrading to Fondue v14

## Introduction

Fondue v14 removes the last legacy components. `@frontify/fondue` no longer has a root entry; everything is imported from a subpath entry.

If you are still on v12 or older, follow the [v13 upgrade guide](https://fondue-components.frontify.com/?path=/docs/documentation-development-upgrading-v13--docs) first.

### Package structure

```
@frontify/fondue
 |
 ├── /components
 |   Contains the react components
 |
 ├── /icons
 |   Contains the icons
 |
 ├── /charts
 |   Contains the charts
 |
 ├── /tokens
 |   Contains the style tokens
 |
 ├── /sdk
 |   Contains the queryable component, token and guide metadata
 |
 ├── /rte
 |   Contains the legacy rich text editor
 |
 └── /rich-text-editor (experimental)
     Contains the new rich text editor
```

## Breaking changes

### Root entry and legacy components

The `@frontify/fondue` root entry has been removed, together with every legacy component, hook and utility it exported.

#### Required changes

Replace each import from `@frontify/fondue` with its subpath entry.

```jsx
- import { Tree } from '@frontify/fondue';
+ import { Tree } from '@frontify/fondue/components';
```

The following exports of the root entry have been removed. See the [component migration guide](https://github.com/Frontify/fondue/blob/main/packages/components/MIGRATING.md) for the replacement of each component.

#### Removed components

- `Accordion`
- `ActionMenu`
- `AssetInput`
- `Breadcrumbs`
- `CollapsibleWrap`
- `DatePicker`
- `EditableText`
- `FilterableMultiSelect`
- `Flyout`
- `FormControl`
- `FrontifyPattern`
- `InputLabel`
- `LegacyTextarea`
- `MenuItem`
- `MultiSelect`
- `OrderableList`
- `SelectMenu`
- `Toast`
- `Tree`

#### Removed hooks & utilities

- `useCopy`
- `useMemoizedId`
- `useMobileDetection`
- `useForwardedRef`
- `TABBABLE_ELEMENTS`
- `FOCUS_VISIBLE_STYLE`
- `FOCUS_VISIBLE_STYLE_INSET`
- `FOCUS_WITHIN_STYLE`
- `Validation`

### Legacy stylesheet

The `@frontify/fondue/styles` stylesheet only contained styles for the legacy components and has been removed.

#### Required changes

Remove the import. Import the stylesheet of each entry you use instead.

```jsx
- import '@frontify/fondue/styles';
+ import '@frontify/fondue/components/styles';
```

### Legacy tokens

The `@frontify/fondue/legacyTokens/base`, `@frontify/fondue/legacyTokens/tailwind` and `@frontify/fondue/legacyTokens/tools/replaceLegacyTokens` entries have been removed.

`@frontify/fondue-tokens` v6 also removes the `@frontify/fondue-tokens/legacy/tools/replaceLegacyTokens` export.

#### Required changes

Migrate the remaining legacy CSS variables and Tailwind classes to the token system. See [Tokens](https://fondue-components.frontify.com/?path=/docs/documentation-development-upgrading-v13--docs#tokens) in the v13 guide.

If you still need the `migrate-tokens` codemod, run it from v13:

```bash
pnpm --package=@frontify/fondue@v13.0.0 dlx migrate-tokens <path-to-your-project>
```

### Standalone packages

If you depend on the standalone packages directly rather than on `@frontify/fondue`, update them together. Components and charts require `@frontify/fondue-tokens` 6 as a peer dependency.

| Package                             | v14 version |
| ----------------------------------- | ----------- |
| `@frontify/fondue-tokens`           | 6.x         |
| `@frontify/fondue-components`       | 37.x        |
| `@frontify/fondue-charts`           | 10.x        |
| `@frontify/fondue-icons`            | 1.x         |
| `@frontify/fondue-sdk`              | 1.x         |
| `@frontify/fondue-rte`              | 0.2.x       |
| `@frontify/fondue-rich-text-editor` | 0.1.x       |

## New in v14

### Rich text editor (experimental)

The new rich text editor is available from `@frontify/fondue/rich-text-editor`, with its styles in `@frontify/fondue/rich-text-editor/styles`.

It is **experimental**: its API and stored document format can change in any release, including minor and patch releases, until it reaches 1.0. The legacy editor in `@frontify/fondue/rte` is unchanged.
