# `core`

The document, paragraphs, text and hard breaks that every model installs.

| Feature | Commands and payloads | Keys | Controls | Input rules | Document change |
|---|---|---|---|---|---|
| `core` | `text.insert` with `{ text }` | none | none | none | Holds `doc`, `paragraph`, `text` and `hard_break`; typing inserts text, and `text.insert` replaces the selection with its `text` |
