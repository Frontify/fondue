# Keyboard reference

Every key the editor binds, grouped by who binds it. `Mod` is ⌘ on Apple systems and Ctrl everywhere else, so each table shows both.

Each table is written from the plugin's own hotkeys, so a key that one of the plugins below gains appears here with no edit to this page.

<PluginKeyboardReference plugins={[...defaultPlugins, mentionPlugin({ items: [] })]} />

An editor that submits on Enter (`blurOnBreakPlugin`) changes two keys: Enter submits outside a list, and Shift+Enter starts a new paragraph or list item instead of a line break.
