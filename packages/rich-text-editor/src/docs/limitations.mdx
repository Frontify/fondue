# Limitations

The docs, the stories and the locale files mention some features that no shipped profile installs. This page lists each of them. A feature that a story or a docs page names is either installed in at least one of the profiles Inline, Comment, Document and Brand document, or is listed here.

## Features that no shipped profile installs

| Feature ID         | What it is                                               | Where it is mentioned                                                                                                                                                                                                                                              |
| ------------------ | -------------------------------------------------------- | ------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------ |
| `tables`           | Tables                                                   | The content check `table.no-header`, in the accessibility checks story and the Accessibility guide. The locale strings `RichTextEditor_checkTableNoHeader` and `RichTextEditor_checkTableNoHeaderHelp`.                                                            |
| `media.embed`      | Video and link embeds                                    | The content checks `embed.title-missing` and `embed.media-review`. The locale strings `RichTextEditor_checkEmbedTitleMissing`, `RichTextEditor_checkEmbedTitleMissingHelp`, `RichTextEditor_checkEmbedMediaReview` and `RichTextEditor_checkEmbedMediaReviewHelp`. |
| `marks.highlight`  | Highlight colours                                        | The `marks.font-color` story, which offers highlight colours when this feature is installed. The locale strings `RichTextEditor_highlightColors` and `RichTextEditor_customHighlight`.                                                                             |
| `blocks.indent`    | Text indent for paragraphs and headings                  | Nowhere else.                                                                                                                                                                                                                                                      |
| `nav.find-replace` | Find and replace                                         | The accessibility checks story, which places its button in the find and replace group.                                                                                                                                                                             |
| `blocks.handle`    | Block handle, drag and drop of blocks and the block menu | Nowhere else.                                                                                                                                                                                                                                                      |

## What this means for a host

- `featuresById` throws `DefinitionError` with the code `definition.unknown-feature` for each of these IDs. No profile list holds them, and the registry has no factory for them.
- A stored document that uses one of them still loads. A node or mark of a feature the model does not install stays in the document as an opaque island or a kept unknown mark. The reader shows an island as a labelled fallback with its text, and one notice for the document.
- `findContentIssues` has rules for table and embed nodes. No shipped profile creates those nodes.
